# Community conduct

Participate respectfully. Discuss technical decisions with evidence and
constructive criticism. Harassment, discrimination, threats, doxxing, and
disclosure of private data are not acceptable. Respect contributor boundaries,
accessibility needs, and attribution. These expectations apply to issues, pull
requests, reviews, and other project community spaces.

Repository maintainers may remove disruptive content or limit participation.
Moderation should consider context and be proportionate.

## Report a concern

Use [GitHub Report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
for abusive content or behavior on GitHub. Open the content's menu and select
**Report content**, or follow GitHub's reporting instructions for a user or
repository. **GitHub handles these reports** under its own policies; they do not
go to a separate Varendo enforcement team.

Keep personal or sensitive incident details out of public issues. For a software
vulnerability, use the private process in [SECURITY.md](SECURITY.md).
