# ADR 006-owned-system: Opinionated system, bounded customization

Status: Accepted.

## Decision

Aeliqo ships tokens, patterns, component defaults and design constraints. Applications supply meaning, authority and branded token/approved-part overrides, not arbitrary executable agent-generated UI. Studio edits the same manifests as code.

## Consequences

This ADR records a design decision. Replacing it requires explicit alternatives, migration guidance, and conformance tests.
