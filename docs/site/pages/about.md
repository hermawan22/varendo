## What Varendo provides

Varendo turns a validated application intent into a registered interface. The
five packages cover contracts, runtime evaluation, web components, React
bindings, and optional agent transports. Manual application code can use the
same runtime without connecting an agent.

## What the application owns

Your application remains responsible for authentication, server authorization,
data access, routing, business actions, provider policy, and operations. Varendo
validates inputs and coordinates registered behavior; it does not become your
application backend.
