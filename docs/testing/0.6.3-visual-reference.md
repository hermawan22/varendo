## Approval and limits

The independent visual reviewer recommends approving the exact proposed source
and fixture digest as the new fixed reference. This recommendation is based on
complete byte equality with the historical reviewed captures and the fresh
inspections above. It does not turn the diagnostic probe into an approved gate.
This metadata change records maintainer approval of that exact source, fixture
and runner. The subsequent full strict comparison remains a separate step under the [approval procedure](visual-review.md#establish-or-change-approval).

Any approval must retain the exact runner reported by all three browser shards,
two byte-identical captures, zero diff pixels, and threshold zero. The metadata
commit should name this reviewed source and fixture digest; a later strict run
must compare its candidate against this fixed source with the same runner.
Keep probe and strict-gate artifacts separate.

The complete PNG inventory comparison does not mean every frame received a new
full-resolution manual review. Historical review plus exact byte equality and
fresh targeted inspections provide the stated visual evidence. This is not
assistive-technology acceptance, a real-model success measurement, a performance
qualification, package publication, or production deployment evidence.
