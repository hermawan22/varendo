# Varendo 0.2.0 visual reference review

Review date: 20 October 2026. Reference source:
`761f57e85bff9af61ab3fc4d154154514794f829`. Fixture digest:
`813b3594d04c614b233716275f3de529c7247b7fd0f60a3e2d35aea293d2ae2c`.

## Why the reference was renewed

The 0.2.0 source renames every remaining former-name identifier to Varendo:
custom elements, events, CSS custom properties, data attributes, types and
package-internal names. That rename changed the visual fixture digest, so the
strict comparison on the rename's main push correctly rejected the mismatch
before capturing images. That failure was not evidence of a visual regression.

Independent recomputation reproduces the new digest. Compared with the previous
reference's last approved candidate `5177365e3690bd5fee942897a17175ee3b496d4d`,
the 60 fixture paths keep the same count and layout after mapping
`Aeliqo`/`aeliqo`/`AELIQO` to `Varendo`/`varendo`/`VARENDO` in paths and
contents. Sixteen are byte-identical and 33 identical after that mapping. The
remaining eleven add only Prettier line wrapping of lines the longer name pushed
past the print width, and the catalog example's package version `0.2.0`. The
738 package and design-token sources show the same pattern: renames, Prettier
wrapping and the `0.2.0` version strings, with no other change. No capture
infrastructure, inventory, hash exclusion or comparison threshold changed. The
[0.1.0 review](0.1.0-visual-reference.md) remains intact.

## Acceptance

The accompanying metadata records acceptance of this exact source, fixture and
runner following the owner-requested settlement of the rename and this evidence
review. The strict comparison retains two byte-identical captures per source,
zero allowed diff pixels, threshold zero, complete inventories and independent
baseline/candidate builds. Its subsequent result remains separate from this
probe and review; see the [approval procedure](visual-review.md#establish-or-change-approval).

Static image comparison is not assistive-technology acceptance, accessibility
conformance, real-model evidence, performance qualification, package
publication or production deployment evidence.
