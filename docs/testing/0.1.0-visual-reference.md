Review date: 12 October 2026. Reference source:
`e50eda3f3b34a2957e5cd1f9f9228c32d3e4c84a`. Fixture digest:
`52ceca6a23fcecd6f12db7e6cb32a3b2cafa3074bb1048e4287ae2a523295113`.

## Why the reference was renewed

The inherited approved source belongs to the retired upstream Git history and
is unavailable in the independent Varendo repository. Its fixture digest also
differs from Varendo's fixtures. The previous strict comparison correctly
rejected that mismatch before capturing images. Fetching more Varendo history
cannot recover an upstream commit that is absent from this repository.

Independent reconstruction of the 54 included files reproduces both the old
`99515fd220704b5ea51993d0090c802ec8ecf0e1b47f64a4c07d25fa8ce8ee79`
and the new digest. Fourteen fixture paths changed: twelve catalog example files,
the field-state type import and the fixture document title. Those differences
are Varendo package imports and source strings, the catalog package identity and
version, and the page title. No capture infrastructure, inventory, hash exclusion
or comparison threshold changed. Production behavior also evolved after the old
reference, so namespace-only fixture differences do not establish historical
pixel equality. The [0.6.3 review](0.6.3-visual-reference.md) remains intact.

## Image inspection and acceptance

Downloaded archive sizes and SHA-256 digests match GitHub's artifact metadata;
all ZIP members pass CRC verification. Every candidate PNG was independently
rehashed against its reported digest and compared with its actual repeated
capture bytes. The raw executed test reports independently reproduce every
shard's complete 610-test successful inventory. The complete archives and exact
inspection-path receipts are retained in protected maintainer storage beyond
GitHub's seven-day artifact retention.

Separate browser reviews inspected all 32 contact sheets per browser, covering
all 2,862 candidate images at thumbnail scale. Targeted individual-PNG inspection
covered 24 Chromium, 36 Firefox and 43 WebKit images across all three viewport
variants. Long Firefox calendar/timeline images were downsampled by the viewing
tool; not every image received a full-resolution review.

Inspected states include required-empty and invalid forms, host errors, disabled
and read-only fields, dialogs, focused cells, sorting, paging and selection,
chart labels and exact-data views, and compound draft/focus continuity. No
blocking visual defect was identified. Narrow tables and comparisons clip
columns within their documented local horizontal-scroll area; they are not
expected to display every column simultaneously. Their surrounding headings,
record scope and paging controls remain contained. Source and automated
geometry checks distinguish these scroll regions from page overflow. This
offline image review did not independently execute scrolling or keyboard input.

The accompanying metadata records acceptance of this exact source, fixture and
runner following the maintainer-requested renewal and independent evidence
reviews. The strict comparison retains two byte-identical captures per source,
zero allowed diff pixels, threshold zero, complete inventories and independent
baseline/candidate builds. Its subsequent result remains separate from this
probe and review; see the [approval procedure](visual-review.md#establish-or-change-approval).

No historical PNG comparison was performed, and no historical pixel equality is
claimed. Static image inspection is not assistive-technology acceptance,
accessibility conformance, real-model evidence, performance qualification,
package publication or production deployment evidence.
